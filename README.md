IOIX is a lightweight Rust CLI tool that gives your project a small "brain" 🧠.

It stores project metadata, commands, and information inside a simple JSON file.

Instead of searching everywhere for:
- project name
- version
- build system
- custom commands
- project information

IOIX keeps them together.

For the latest README and security information, visit GitHub <3

Links:
- [IOIX GitHub](https://github.com/usernullex001/ioix)

- 🚀 Fast and lightweight
- 🦀 Written in Rust

# Usage

Very simple :)

```
ioix <command>
```

## Commands

| Command | Description |
| --- | --- |
| version | IOIX version (not project version) |
| name | Project name |
| fullname | Full project name |
| lang | Project language |
| bs | Build system |
| team | Project team name |
| ver | Project version |
| address | Project author address |
| desc | Project description |
| cmd | Run custom project commands |
| detect | Preview project information |
| viv | Version alias (ver = viv) |
| cargo-update | Convert/sync cargo.toml and info.json |
| init | Init project :DDDDDD (only info.json xD)|
| usemator | JSON users data (search with grep or other tools :D) (name:Users + Terminator xD)|
| users | usemator but friendly :D |
| runcmd | like cmd but run! windows: cmd /C CMD unix: sh -c CMD |
| build | run ioix -c build runcmd :D |

# Custom Commands :D

Like `npm run`.

Example `info.json`:

```json
"cmds": [
  {
    "name": "build",
    "cmdunix": "cargo build",
    "cmdwind": "cargo build",
    "desc": "Build the project :|"
  },
  {
    "name": "run",
    "error": "Error! The app needs some arguments! Run manually :D",
    "desc": "Run the project :|"
  }
]
```

Run:

```bash
ioix -c build cmd
```

Output:

```
stdout -> command output
stderr -> errors
```
or...
```bash
ioix -c build runcmd
```

IOIX does not magically understand every command :|

# cargo-update

(Yeah... the name is not perfect :D)

This command syncs data between:

```
cargo.toml <-> info.json
```

Example:

```rust
"cvtfv" => {
    ct["package"]["version"] =
    toml::Value::String(file.ver.to_string());
},

"fvtcv" => {
    file.ver =
    ct["package"]["version"].to_string();
},
```

Meaning:

```
ct = cargo.toml
file = info.json

c = cargo
f = file
t = to
```

Short names:

| Short | Full |
| --- | --- |
| v | version |
| d | description |
| n | name |
